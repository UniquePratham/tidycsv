What this cleaner fixes

  • Duplicate rows - repeated lines from concatenated exports are dropped (first copy kept).
  • Empty rows - blank lines that break row counts and imports are removed.
  • Whitespace - leading and trailing spaces around names, emails and numbers are trimmed.
  • Header problems - blank or duplicated column names are renamed to unique names.
  • Suspicious emails - values in email columns that cannot be valid addresses are flagged (never rewritten).
  • Mixed date formats - dates like 13/01/2024 and 2024-01-13 in the same column are normalized to YYYY-MM-DD when, and only when, the day/month order is unambiguous.

Questions people actually ask

Is my file uploaded anywhere?
No. Parsing, cleaning and the download happen in this browser tab (FACT: the page loads only local scripts - you can check the network tab).
How large a file can it handle?
Comfortably a few thousand rows. For 50,000+ rows use the tidycsv.py command-line tool so memory stays on your machine.
Will it guess my date order?
No. 03/04/2024 is ambiguous (March 4 or April 3) and is left untouched; only unambiguous values such as 13/01/2024 are converted.
