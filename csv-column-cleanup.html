Clean the columns

Whitespace: the invisible import killer

"Alice " is not "Alice". A trailing space in a name column makes a VLOOKUP miss, makes a COUNTIF report two "identical" values, and makes a CRM create a second contact. Leading spaces usually come from fixed-width exports; trailing spaces from pasted values. The tool trims every cell and reports how many were touched, without changing anything inside the value.

Header names worth normalizing

  • Blank headers - a column with no name gets column_N.
  • Duplicates - email,email becomes email and email_2, because duplicate names silently break name-based mapping in most tools.
  • Stray whitespace in headers - " city " becomes city.
  • Consistent casing - pick one convention (first_name style works almost everywhere) and apply it on export, not by hand, every time.

Keep header names stable across exports: downstream formulas, saved imports and API field maps all refer to them by string.

Column cleanup checklist

  1. Trim whitespace everywhere (tool above).
  2. Repair blank/duplicate headers (tool above).
  3. Verify the columns your destination requires actually exist and are spelled consistently.
  4. Run the full cleaner for dates, emails and duplicates.
  5. Check types after import: IDs that look numeric may need to stay text (leading zeros).

Questions

Does trimming remove spaces inside values?
No - only leading and trailing. New York stays New York.
Will renamed headers break my formulas?
If you reference columns by name in the same file, update the reference; blank and duplicate headers were already unusable for name-based formulas.
What about spaces that are not ASCII?
Non-breaking spaces ( ) often survive a trim. If a value still looks padded after cleaning, check CSV encoding problems.
