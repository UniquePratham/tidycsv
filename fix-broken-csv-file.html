The order that fixes most files

  1. Encoding (characters must read correctly before anything else).
  2. Delimiter (the preview must show columns, not one blob).
  3. Structure (headers and row widths).
  4. Content (whitespace, dates, emails, duplicates) via the full cleaner.
  5. Validate with a staging import: row count plus a handful of known-good records.
