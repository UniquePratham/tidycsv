De-duplicate your CSV

Why CSV files end up with duplicate rows

  • Re-run exports - a report that appends to the same file instead of replacing it.
  • Merged files - someone concatenated last month's export with this month's.
  • Copy-paste rounds - rows pasted twice while cleaning in a spreadsheet.
  • Invisible whitespace - Alice and Alice  look identical but compare as different rows, so naive dedupe misses them.

How this dedupe decides

Every cell is trimmed first, then the whole row is compared as a key. The first occurrence is kept; later matches are dropped and counted. Completely empty rows are removed as well, because they break row counts and most importers. Rows that differ in even one cell are always kept - this is exact matching, not fuzzy matching, so nothing is merged by guesswork.

Bob ,Paris       <- dropped (trailing space made it look different)

The spreadsheet way (for completeness)

In Excel: select the range, Data > Remove Duplicates. In Google Sheets: Data > Data cleanup > Remove duplicates. Both compare raw cell values, so run a trim on the columns first or you will miss whitespace duplicates. The tool above trims and dedupes in one pass, and shows you exactly how many rows each rule touched.

Questions

Does it keep the first or the last copy?
The first occurrence, in file order, so original ordering of unique rows is preserved.
Is dedupe case-sensitive?
Yes - alice@x.io and Alice@x.io are different rows here. Nothing is lowercased without you asking.
Can it merge rows that are similar but not identical?
No, on purpose. Fuzzy merging can delete real data; you get an exact-match tool and a visible count of what was dropped.
